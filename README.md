# STC89C52 光强感应自动车灯控制系统

单片机原理及应用课程设计（2025.12）。用光敏电阻 + LM393 电压比较器检测环境光强，低于阈值时点亮车灯 LED，同时用数码管显示实时时间、用 OLED 显示课题信息。

> **关于本仓库**：课设于 2025.12 完成，开发板是课程统一提供的，现已不在手上。仓库里的原理图、实物照片与软件说明，是从当时的课程设计说明书中整理出来的复盘归档。

## 功能

- 光强低于阈值：车灯 LED（2 路）点亮；高于阈值：熄灭
- 按键可手动开启 / 关闭自动控制
- 实时时间显示，时间可通过按键调整
- OLED 显示设计者姓名、班级、学号与课题名称

## 硬件组成

| 器件 | 型号 / 参数 | 说明 |
| --- | --- | --- |
| 主控 | STC89C52RC | 12MHz 晶振 CRY1，负载电容 C1/C2 取 30pF |
| 光强检测 | 光敏电阻 + LM393DR 电压比较器 | R1 10kΩ 与光敏电阻分压后送进比较器 |
| 阈值设定 | PR1 10kΩ 电位器 | 阈值在硬件上拧电位器调整，比较器输出送单片机 IO |
| 显示 | OLED NFP1315-157BY | 显示姓名 / 学号 / 课题名称 |
| 输出 | 车灯 LED（2 路） | 由控制系统使能位与光强判定共同决定亮灭；任务书要求 8 路，开发板 IO 被数码管与 OLED 占用，实际只接 2 路 |
| 输入 | 独立按键 | 工作模式切换与开关控制 |

原理图与实物照片见 hardware/ 目录。

## 软件结构

| 文件 | 作用 |
| --- | --- |
| Key.c | 按键扫描与消抖（软件减速计数） |
| Seg.c | 数码管动态扫描：时间显示 / 时间设置 / 光强值显示三个界面 |
| Oled.c | OLED 显示驱动 |
| Adc.c | 光强采样 |
| main.c | 主循环 + 工作模式状态机（自动控制模式 / 时间调整模式） |

任务节拍：Timer0 定时 1ms（12.000MHz），中断里只给各任务的软件计数器加一；主循环里按键、数码管、光强采样、OLED、LED 各自跑到自己的计数值才执行一次。用计数减速代替长延时，是这颗 51 资源紧的情况下分任务的主要办法。

## 已知不足

- 光强只有亮 / 灭两档，拿不到连续 AD 值：LM393 是电压比较器，输出的是开关量而不是模拟量
- 阈值靠电位器手调，程序里没有数字阈值，也没做阈值回读
- 车灯只接了 2 路 LED：开发板 IO 已被数码管与 OLED 占用，引不出 8 路，任务书要求的 8 路没有全部接上
- 没有做时间维度滤波，快速遮挡时判定会跟着抖

## 如何运行

原始 Keil 工程在当年做课设的电脑上，暂未随仓库提供。当时的流程是：

1. 用 Keil C51 编译生成 .hex
2. 用 STC-ISP 通过串口把 .hex 下载进 STC89C52 开发板
3. 上电后看数码管与 OLED；遮住光敏电阻，观察车灯 LED 的亮灭
